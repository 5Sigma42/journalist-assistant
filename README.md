# Journalist Assistant – Anmeldeseite

Statische Anmeldeseite für das Partner-Portal des Journalist Assistant (Testversion, Prototyp).

Die Seite enthält keine Zugangsdaten und keine Logik zur Prüfung. Sie schickt Zugang und Passwort per HTTPS an das Portal, das die Anmeldung prüft. Sie liegt hier, weil die Portal-Seiten selbst in einer Browser-Sandbox ausgeliefert werden und Firefox dort bei Passwortfeldern eine irreführende Warnung zeigt.

Aufruf: `https://5sigma42.github.io/journalist-assistant/?k=<zugang>`
